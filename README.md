---

## 📌 Descripción / Description

**ES:**  
Sport1874 es una aplicación web de comercio electrónico donde podés explorar y comprar prendas de marcas reconocidas como **Polo**, **Nike**, **Tommy Hilfiger**, entre otras. Todos los productos están en impecable estado, cuidadosamente seleccionados por su CEO.

**EN:**  
Sport1874 is a web-based e-commerce application where you can browse and purchase clothing from top brands such as **Polo**, **Nike**, **Tommy Hilfiger**, and more. All items are in excellent condition, handpicked and curated by the CEO.

## 🔐 Autenticación y Roles / Authentication & Roles

**ES:**  
El panel administrativo cuenta con protección mediante inicio de sesión.  
- Autenticación por rol (administrador)  
- Persistencia de sesión con `localStorage`

**EN:**  
The admin panel is protected by login authentication.  
- Role-based access (admin)  
- Session persistence using `localStorage`

## 🛠️ Instalación / Installation


1. Cloná el repositorio / Clone the repo:
git clone https://github.com/Juancho1999/sports1874_ecommerce.git

2. Instalá las dependencias / Install dependencies:

        npm install

3. Ejecutá la app en desarrollo / Run the app in development:

            npm run dev

## Unica forma de acceder al Panel Administrativo es mediante la siguiente ruta: /admin
